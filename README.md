# ELU install demo — sample data only

Independent copy of the V9 rehearsal structure, with a working PWA service worker. It contains demo entries only and changes are in-memory. It is suitable for a public HTTPS installation trial. It does not contain the working production app, resident records, actual photos, or stored browser data. Do not use for field work.

Upload the *contents* to a separate path on an HTTPS host. PWABuilder can then check its URL and package it for Android/Windows testing. Uploading to a subfolder of the public rehearsal repository does not require changing its existing root files. This is for evaluating the installed look and navigation only; do not infer that real app features or data sync work.
